# Эталонный шаблон демо-сайта автосервиса

Файлы:
- `index.html` — разметка с подстановками;
- `style.css` — стили, mobile-first, без фреймворков;
- в конце `index.html` — встроенный мини-скрипт (~3 КБ, без библиотек): статус «открыто сейчас», появление карточек, блик кнопки звонка, текст заявки в мессенджер. Без JS страница работает целиком: всё видно, ссылки ведут на звонок или мессенджер;
- `fonts/` — Sofia Sans и Sofia Sans Extra Condensed (woff2, лицензия OFL 1.1 в `fonts/OFL.txt`); сайт не ходит в Google Fonts.

`build.js` встраивает `style.css` в `<style>` каждой страницы, а шрифты — внутрь CSS как `data:` URI (latin-ext со знаком ₽ — только если на странице есть цены). Поэтому `site/{slug}/index.html` — один самодостаточный файл (около 160 КБ): он открывается локально (`file://`), в превью и по любому пути.

Иконки собраны в SVG-спрайт в начале `<body>`. У каждой иконки размеры и обводка (`width`, `height`, `stroke`) заданы атрибутами, так что даже без CSS они не раздуваются.

## Синтаксис подстановок

| Запись | Что делает |
|---|---|
| `{{key}}` | Значение с HTML-экранированием. Можно указать путь: `{{phones.0.href}}`. |
| `{{#if key}}…{{else}}…{{/if}}` | Блок выводится, если значение не пустое: непустая строка после trim, непустой массив или `true`. |
| `{{#if a \|\| b}}…{{/if}}` | Блок выводится, если не пустое хотя бы одно из значений. |
| `{{#each key}}…{{/each}}` | Повтор блока для каждого элемента массива. Внутри доступны поля элемента, а `{{this}}` — сама строка. |

Сырой HTML не вставляется: экранируется всё. Если ключа нет в JSON, сборка должна падать с ошибкой: так ловятся опечатки. Пустое значение (`""` или `[]`) — это норма, блок просто скрывается.

## Поля `content/{slug}.json`

Эталон: `content/vag-market.json`. Правило одно: **только факты из источника**. Если данных нет, поле остаётся пустым, и блок на странице скрывается.

| Поле | Тип | Где выводится | Если пусто |
|---|---|---|---|
| `slug` | строка | имя папки `site/{slug}/` | обязательно |
| `title`, `description` | строка | `<title>`, meta description | `title` обязателен |
| `name` | строка | табличка, подвал | обязательно |
| `category` | строка | табличка, рядом с пиктограммой | скрыто |
| `tagline` | строка | табличка, под названием (одна строка по фактам) | скрыто |
| `city`, `address`, `address_note` | строка | табличка, блок «Контакты» | скрыто |
| `timezone` | строка (IANA) | часовой пояс города для статуса «открыто сейчас»: Тюмень — `Asia/Yekaterinburg`, Москва — `Europe/Moscow` | статус не показывается |
| `hours_lines` | строки | табличка, каждая строка отдельно: `"Пн–Пт 9:00–20:00"` | скрыто |
| `week` | `{day, day_full, open, close, closed}` | полоса «Режим работы», 7 дней | скрыто |
| `rating`, `rating_count`, `rating_source` | строка | табличка (строкой, если нет `stats`) | скрыто |
| `stats` | `{value, label}` | полоса крупных цифр на первом экране: рейтинг 2ГИС, число оценок, 1 факт компании (гарантия, масштаб) | скрыто |
| `phones` | `{value, href, label?}` | «Контакты»; первый номер — оранжевая кнопка «Позвонить: {номер}» на всю ширину и закреплённая нижняя панель на телефоне | скрыто; главной кнопкой становится 2ГИС |
| `messengers` | `{label, href}` | вторая кнопка на табличке («Написать в WhatsApp»); первая ссылка — цель кнопок «Узнать точную цену» в услугах (скрипт добавляет `?text=Здравствуйте! Подскажите по стоимости: {услуга}`). Только с настоящим адресом мессенджера | скрыто; услуги ведут на звонок |
| `links` | `{label, value, href}` | «Контакты» (сайт, мессенджеры) | скрыто |
| `map_url`, `map_label` | строка | ссылка «Маршрут в 2ГИС» под адресом, строка в «Контактах», кнопка в нижней панели | скрыто |
| `services` | `{title, price?, text?, icon?}` | «Услуги и цены»: название слева, цена «от … ₽» справа, строка пояснения под ним. Без `price` пишется «по запросу». Иконку-бейдж (`engine`, `oil`, `suspension`, `diagnostics`, `electrics`, `brakes`, `tires`, `climate`, `transmission`, `body`, `exhaust`, `wash`, `tuning`, `parts`, `car`, `service`) `build.js` выбирает по названию; `icon` в JSON её переопределяет | скрыто |
| `steps` | `{num, title, text}` | «Как проходит работа»: 3–4 шага с крупными номерами. Только из фактов: «Ремонт с гарантией» — если гарантия есть в источнике, «Согласование стоимости» — если источник это описывает | скрыто |
| `prices_note` | строка | под «Услугами и ценами»: откуда цены и дата прайса | скрыто |
| `prices` | — | устарело, не выводится (цены теперь в `services`) | — |
| `reviews`, `reviews_note` | `{text}` | «Что хвалят клиенты»: пересказ, без имён | скрыто |
| `about` | строки (абзацы) | «Об автосервисе» | скрыто |
| `features` | строки | список удобств | скрыто |
| `source_url`, `source_label`, `data_date` | строка | подвал: источник и дата данных | скрыто |
| `_source` | объект | не выводится: заметки об исходной записи | — |

Правила заполнения:
- Цены переносятся дословно, как в источнике, с датой в `prices_note`. Внутри чисел ставится неразрывный пробел: `"от 1 500 ₽"`.
- Отзывы пишутся только пересказом, без имён, инициалов и аватаров.
- `week`: день без данных в массив не включается. Выходной ставится (`"closed": true`) только если источник прямо пишет «выходной».
- Из ссылок 2ГИС удаляются параметры `inv_by` и `inv_ts`: это метки того, кто поделился ссылкой.

## Обязательные элементы (не удалять)

- Плашка «Демо-концепт, не официальный сайт, удалим по первой просьбе» — сверху (`.demo-bar`) и снизу (`.demo-plate`).
- `<meta name="robots" content="noindex, nofollow, noarchive">` и аналоги для Google и Яндекса. На шаге 6 в корень `site/` стоит добавить ещё `robots.txt` с `Disallow: /`.

## Дизайн-решения

- **Идея:** тёмный графитовый цех. Первый экран — стальная табличка на воротах бокса: заклёпки по углам, полоса предупредительной разметки (оранжевый/графит под 45°) по верхней кромке, крупное узкое название.
- **Цвета** (токены в `:root`): фон `#0E1013`, карточки `#171A1F`, плитки `#1F2329`, швы `#2B3038`, текст `#FFFFFF`, второстепенный `#A7ADB5`, акцент `#F97316`. **Синего нет нигде.** Контраст: белый на фоне 18:1, второстепенный 7.8:1, оранжевый на фоне 7:1. На оранжевой кнопке текст тёмный (`#0E1013`, 7:1): белый дал бы только 2.8:1.
- **Плашки «Демо-концепт»:** сверху полоса разметки над строкой текста, снизу карточка в рамке из той же разметки, как временное ограждение.
- **Шрифты:** узкий Sofia Sans Extra Condensed 800 для названия и заголовков разделов, Sofia Sans 400/600/700 для текста. Без капса и без надписей-«бровей»; у заголовка раздела короткая оранжевая метка слева.
- **Первый экран:** название → адрес с компактной ссылкой «Маршрут в 2ГИС» → часы → оранжевая кнопка «Позвонить: {номер}» на всю ширину (и «Написать в мессенджер», если есть адрес) → полоса крупных цифр: рейтинг, оценки, факт компании.
- **Блоки:** график — полоса из 7 плиток с оранжевой кромкой, выходной заштрихован; «Услуги и цены» — прайс-лист: название крупно слева, цена «от … ₽» крупным узким шрифтом справа (или «по запросу»), строка пояснения под ним; «Что хвалят клиенты» — пересказ с оранжевой галочкой.
- **Атмосфера:** на табличке — инженерная сетка 24 px (CSS-градиенты, гаснет к низу) и тёплое оранжевое свечение в углу; у страницы — мягкое свечение сверху. Картинок нет.
- **Схема автомобиля:** на табличке справа за названием — тонкая векторная схема кузова и колёс (встроенный SVG, графит с оранжевыми выносками), гаснет к левому краю, чтобы не мешать тексту.
- **Иконки услуг:** 16 технических иконок 32×32 в одном стиле (контур 1.75, оранжевый) на стальном бейдже 48×48 с сеткой и меткой в углу.
- **«Как проходит работа»:** номера 01–04 крупным узким шрифтом контуром; на телефоне шаги идут столбиком, соединены пунктиром, с 560 px — сеткой 2×2.
- **Статус работы:** скрипт берёт график со страницы и время в `timezone`. Зелёная пульсирующая точка «Открыто до 20:00» — только если сервис действительно открыт; иначе серая «Закрыто, откроется завтра в 9:00». Сегодняшний день подсвечен в полосе графика.
- **Микроанимации:** карточки плавно появляются при прокрутке (IntersectionObserver, только `opacity` и `transform`); по нажатию на «Позвонить» — короткий блик и лёгкое вдавливание; у карточек услуг при наведении подсвечивается граница. Плашка «Демо-концепт» никогда не скрывается. При `prefers-reduced-motion` и без JS анимаций нет, всё видно сразу.
- **Заявка из услуги:** вся карточка кликабельна («Узнать точную цену»): мессенджер с готовым текстом, если в данных есть его адрес, иначе звонок `tel:`.
- **Скругления** жёсткие, по иерархии: табличка 8, карточка 6, кнопка 4, плитка 3 px.
- **Нижняя панель** (только при телефоне): «Позвонить в сервис» и квадратная кнопка маршрута, матовое стекло (`backdrop-filter`, в старых браузерах — плотный графит). На телефоне закреплена внизу экрана всегда (`position: sticky`, последний элемент страницы: в конце встаёт под подвал), с 768 px скрыта.
- **Корень сайта** (`site/index.html`) — заглушка без списка: каждая страница открывается только по прямой ссылке `/{slug}/`.
- **Проверено** на 360, 414 и 1024 px: горизонтальной прокрутки нет, кнопки 52–60 px, длинные адреса и номера с добавочным переносятся.
