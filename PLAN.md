## Данные 2ГИС
- `scripts/fetch-2gis.js` берёт ID из ссылок в `local_businesses.md`, запрашивает официальный Catalog API 2ГИС (`catalog.api.2gis.com/3.0/items/byid`), сохраняет сырые ответы в `data/2gis/{id}.json` и переписывает раздел «Данные 2ГИС» в `local_businesses.md`.
- Ключ в репозитории не хранится, только в переменной окружения при запуске. В облачной сессии Node нужен ещё `NODE_USE_ENV_PROXY=1`:
  `DGIS_KEY=… NODE_USE_ENV_PROXY=1 node scripts/fetch-2gis.js`
- Получено по всем 10 организациям: название, город, адрес, рейтинг, число отзывов и оценок, рубрики, атрибуты, график.
- API не вернул для этого ключа телефоны и сайты (`contact_groups`). Текстов отзывов и цен в API нет.
