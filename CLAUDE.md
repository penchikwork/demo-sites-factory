# Правила проекта

- Никогда не выдумывать данные бизнеса: если данных нет — поле пустое, блок на странице скрывается.
- Отзывы публиковать только пересказом, без имён авторов.
- На каждой странице обязательна плашка: «Демо-концепт, не официальный сайт, удалим по первой просьбе» и запрет индексации (`noindex`).
- Стек: чистая статика (HTML + CSS), один скрипт сборки `build.js`, без тяжелых фреймворков.
- Мобильная вёрстка в приоритете (360px–414px без горизонтальной прокрутки).
- Обязательно использовать подключённые навыки `ui-ux-pro-max` и `frontend-design` при проектировании эталонного шаблона.
